# GPS取得動作確認テスト（FR-08 / #689）

条件入力の Step 1（P-02 `/plan/new?step=1`）の「現在地を使う」で、現在地を出発地に入れられることを確認する。

## 自動テストで確認済みのこと

`carrip/e2e/gps.spec.ts`（`npm run test:e2e -- e2e/gps.spec.ts`）。位置情報はブラウザの機能で疑似的に与える。

| 内容 | Chrome | Edge | WebKit | スマホ幅 Chromium | スマホ幅 WebKit |
|---|---|---|---|---|---|
| 許可すると座標が出発地に入り、その出発地で行き先画面まで進める | ✅ | ✅ | ✅ | ✅ | ✅ |
| 拒否するとメッセージが出て、出発地を手入力して先に進める（フォールバック） | ✅ | ✅ | ✅ | ✅ | ✅ |

（2026-10-31、ローカル。Chrome 156 / Edge 156 / WebKit 27.2）

自動テストは**実機の GPS・OS の許可ダイアログ・iOS の Safari 本体を使わない**ため、以下の手順で人が確認する。

## 前提

- テストは **https の本番環境またはプレビュー環境**で行う
  - 位置情報は https の画面でのみ使える。スマホから PC の開発サーバー（`http://192.168.x.x:3000` など）を開くと必ず失敗する
- 屋外または窓の近くなど、位置情報が取りやすい場所で行う

## 手順

### A. 許可したとき

1. 条件入力の Step 1 を開く
2. 「現在地を使う」を押す
3. 端末・ブラウザの確認で「許可」を選ぶ
4. ボタンが「現在地を取得中…」になり、出発地に `現在地（緯度, 経度）` が入ることを確認する
5. 地図アプリなどで、その座標が今いる場所の近くであることを確認する
6. そのまま条件を入力して「ルートと料金」まで進み、出発地点が今いる場所になっていることを確認する

### B. 拒否したとき（フォールバック）

1. ブラウザのサイト設定で位置情報の許可を取り消す（iPhone：設定 → Safari → 位置情報 → 「拒否」、Chrome：アドレスバーの鍵アイコン → 位置情報 → ブロック）
2. 「現在地を使う」を押す
3. 「位置情報の利用が許可されていません。出発地を入力してください」と表示されることを確認する
4. 出発地を手入力して、次へ進めることを確認する

### C. 端末の位置情報サービスがオフのとき（任意）

1. 端末の位置情報サービスをオフにする
2. 「現在地を使う」を押し、メッセージが出て手入力に戻れることを確認する
