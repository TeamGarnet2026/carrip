# エラーカタログ — DriveRoute Optimizer

**文書バージョン**: v1.0  
**対象フェーズ**: MVP（Phase 1）

> 本文書はAPIエラーコード・ユーザー向けメッセージ・挙動・フォールバックを一元管理します。
> 実装者はこのカタログを参照してエラーハンドリングを統一してください。

---

## エラーコード体系

```
DR-{カテゴリ}-{連番}

カテゴリ:
  INP = 入力バリデーションエラー
  RTE = ルート生成エラー
  EXT = 外部API連携エラー
  AUTH = 認証・認可エラー
  SYS = システムエラー
```

## 1. 入力バリデーションエラー（DR-INP）

| エラーコード | 発生条件 | HTTPステータス | ユーザー向けメッセージ | 挙動 |
|---|---|---|---|---|
| DR-INP-001 | 出発地が Google Places で認識されない住所 | 400 | 「出発地を正しく入力してください。住所候補から選択してください。」 | 該当フィールドを赤枠表示。入力をブロック |
| DR-INP-002 | 訪問都道府県が未選択 | 400 | 「訪問する都道府県を1つ以上選択してください。」 | Step 2 に戻る |
| DR-INP-003 | 訪問都道府県が6件以上 | 400 | 「訪問都道府県は最大5件まで選択できます。」 | 6件目の選択を無効化 |
| DR-INP-004 | 出発日が過去または180日超 | 400 | 「出発日は今日から180日以内で設定してください。」 | カレンダーで範囲外の日付をグレーアウト |
| DR-INP-005 | 人数が範囲外（0または16以上） | 400 | 「人数は1〜15名で設定してください。」 | ステッパーの限界でボタン無効化 |
| DR-INP-006 | 旅行日数が範囲外（0または8以上） | 400 | 「旅行日数は1〜7日で設定してください。」 | ステッパーの限界でボタン無効化 |
| DR-INP-007 | カスタム燃費が不正値（0以下または200超） | 400 | 「燃費は1〜200 km/L の範囲で入力してください。」 | フィールドを赤枠表示 |

## 2. ルート生成エラー（DR-RTE）

| エラーコード | 発生条件 | HTTPステータス | ユーザー向けメッセージ | 挙動 |
|---|---|---|---|---|
| DR-RTE-001 | 指定エリアのPOI候補が3件未満（フィルタ後） | 422 | 「指定条件でルートを組めませんでした。条件を変更してもう一度お試しください。」 | 「条件を変更する」ボタンを表示。入力画面に戻る |
| DR-RTE-002 | 1日の走行時間が24時間を超えるルートのみ生成された | 422 | 「日程が詰まりすぎています。日数を増やすか、訪問エリアを減らしてください。」 | 日数・エリア変更を促す |
| DR-RTE-003 | ルート生成タイムアウト（30秒超） | 504 | 「ルートの生成に時間がかかっています。しばらく待ってから再試行してください。」 | 「再試行」ボタン表示。30秒後に自動リトライ×1 |
| DR-RTE-004 | スコアリング後の候補が1件未満 | 422 | 「条件に合うルートが見つかりませんでした。予算や優先軸を調整してください。」 | 優先軸のリセットを提案 |
| DR-RTE-005 | POI の全候補が定休日・営業時間外 | 422 | 「指定日程では訪問可能なスポットが見つかりませんでした。出発日を変更してください。」 | カレンダーを再表示 |

## 3. 外部API連携エラー（DR-EXT）

| エラーコード | 発生条件 | HTTPステータス | ユーザー向けメッセージ | フォールバック挙動 |
|---|---|---|---|---|
| DR-EXT-001 | Google Places API 呼び出し失敗（5xx・タイムアウト） | 503 | 「スポット情報の取得に失敗しました。キャッシュデータで代替しています。」 | Redis キャッシュから最大7日分のPOIを使用。黄色バナーで通知 |
| DR-EXT-002 | Google Routes API 呼び出し失敗 | 503 | 「ルート情報の取得に失敗しました。概算距離を使用しています。」 | DB保存の過去ルートデータで推定計算。バナー表示 |
| DR-EXT-003 | Gemini API 失敗（タイムアウト含む） | — | UIには表示しない（非クリティカル） | LLMコメント欄を空白のまま表示。Sentry にログ送信 |
| DR-EXT-004 | gogo.gs 価格データが古い（7日超） | — | 「ガソリン価格データが古い可能性があります（更新日：YYYY/MM/DD）。」 | 資源エネルギー庁の月次データを使用。更新日を画面表示 |
| DR-EXT-005 | Google Maps API 課金上限到達 | 429 | 「現在アクセスが集中しています。しばらく後にお試しください。」 | エラー画面表示。バックオフ後リトライ（最大3回） |
| DR-EXT-006 | LINE Messaging API 送信失敗 | 503 | 「LINEへの送信に失敗しました。共有URLをコピーして手動で送信してください。」 | 共有URLを画面に表示しコピーボタンを提供 |

## 4. 認証・認可エラー（DR-AUTH）

| エラーコード | 発生条件 | HTTPステータス | ユーザー向けメッセージ | 挙動 |
|---|---|---|---|---|
| DR-AUTH-001 | 未認証ユーザーが認証必須エンドポイントに接触 | 401 | 「この操作にはログインが必要です。」 | ログイン画面にリダイレクト。操作完了後に元画面へ戻る |
| DR-AUTH-002 | 他ユーザーの trips への不正アクセス | 403 | 「このルートを表示する権限がありません。」 | マイページ（/trips）へリダイレクト |
| DR-AUTH-003 | 共有URLが期限切れ | 404 | 「この共有リンクは有効期限（7日）が切れています。幹事に新しいリンクを発行してもらってください。」 | エラーページ表示（再発行を促す） |
| DR-AUTH-004 | 共有URLが存在しない（不正なshort_code） | 404 | 「ページが見つかりません。URLが正しいか確認してください。」 | 404ページ表示 |
| DR-AUTH-005 | JWT トークン期限切れ | 401 | 「セッションが切れました。再度ログインしてください。」 | リフレッシュトークンで自動更新。失敗時はログイン画面へ |

## 5. レート制限エラー（DR-SYS）

| エラーコード | 発生条件 | HTTPステータス | ユーザー向けメッセージ | 挙動 |
|---|---|---|---|---|
| DR-SYS-001 | ルート生成が 10req/分/IP を超過 | 429 | 「リクエストが多すぎます。1分後に再試行してください。」 | Retry-After ヘッダー付きで返却。UIにカウントダウン表示 |
| DR-SYS-002 | サーバーエラー（予期せぬ例外） | 500 | 「予期せぬエラーが発生しました。しばらく後にお試しください。」 | Sentry にスタックトレース送信。エラーID を表示し問い合わせを促す |
| DR-SYS-003 | DB 接続エラー | 503 | 「サービスが一時的に利用できません。しばらく後にお試しください。」 | Sentry アラート → 自動再接続リトライ（最大5回） |

## 6. フロントエンド エラー表示ガイドライン

### 表示パターン

| パターン | 使用場面 | コンポーネント |
|---|---|---|
| **インラインエラー** | 入力フォームのフィールドエラー（DR-INP系） | フィールド下部に赤テキスト |
| **バナー（警告）** | 外部API劣化（DR-EXT系）。操作は継続可能 | 画面上部に黄色バナー |
| **バナー（エラー）** | ルート生成失敗（DR-RTE系） | 画面上部に赤バナー。再試行ボタン付き |
| **フルページエラー** | 認証失敗・404（DR-AUTH系） | 独立ページ。ナビゲーションは維持 |
| **トースト** | 非クリティカルな通知（LINE送信成功等） | 右下に3秒表示 |

### エラーメッセージ作成ルール

1. **何が起きたか**を明示する（「エラーが発生しました」はNG）
2. **ユーザーが次に何をすべきか**を具体的に示す
3. **技術的な詳細**（スタックトレース・エラーコード）はログのみ。UIには出さない
4. エラーIDは問い合わせ用に表示してよい（例：`エラーID: DR-SYS-002-abc123`）

| DR-EXT-001/002 が1時間以内に10件以上 | Slack #alerts | 🟡 中 |
| DR-AUTH-002（不正アクセス）が1時間以内に20件以上 | Slack #alerts | 🔴 高（セキュリティ） |
| DR-RTE-003（タイムアウト）が1時間以内に5件以上 | Slack #dev | 🟡 中 |
