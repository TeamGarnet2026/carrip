## 遷移定義

### メインフロー（旅程作成）

```
P-01（ランディング）
  └─[旅程作成ボタン]──▶ P-02（Step 1）
                            └─[次へ]──▶ P-03（Step 2）
                                          └─[次へ]──▶ P-04（Step 3）
                                                        └─[次へ]──▶ P-05（Step 4 確認）
                                                                      └─[送信]──▶ P-06（生成中）
                                                                                    ├─[成功]──▶ P-07（候補一覧）
                                                                                    └─[失敗]──▶ P-14（エラー）
```

### ウィザード内の戻り遷移

```
P-03 ──[戻る]──▶ P-02
P-04 ──[戻る]──▶ P-03
P-05 ──[戻る]──▶ P-04
```

### 候補一覧からの分岐

```
P-07（候補一覧）
  ├─[「編集する」]──────────▶ P-08（詳細・編集）
  │                               └─[再計算完了]──▶ P-07（候補一覧に戻る）
  ├─[「このルートを選ぶ」]──▶ P-09（プラン確定）
  │                               └─[「マイページへ」]──▶ P-13（マイページ）
  └─[「LINEで共有」]────────▶ P-10（LINE共有）
                                  └─[共有後]──▶ P-11（承認状況確認）
```

### 共有・承認フロー（メンバー側）

```
LINE通知 ──[URLタップ]──▶ P-12（共有閲覧）
                              └─[「参加する」]──▶ P-12（人数更新・完了表示）

P-11（承認状況確認）──[ポーリング/Realtime]──▶ 参加者リスト自動更新
```

### 認証フロー

```
P-09 / P-10 / P-11 / P-13 にアクセス（未認証）
  └─[自動リダイレクト]──▶ ログイン画面（Supabase Auth）
                              └─[認証成功]──▶ 元の画面に戻る
```

## 各画面の詳細仕様

### P-02 入力 Step 1

| 項目 | 仕様 |
|---|---|
| 出発地 | Google Places Autocomplete（有効住所のみ）。GPS取得ボタンあり |
| 出発日 | カレンダーピッカー。今日〜180日後の範囲のみ選択可 |
| 旅行日数 | ステッパー（1〜7日）。デフォルト: 1日 |
| バリデーション | 出発地・出発日が未入力の場合「次へ」ボタンを非活性 |
| エラー | DR-INP-001、DR-INP-004 を参照 |

### P-03 入力 Step 2

| 項目 | 仕様 |
|---|---|
| 訪問都道府県 | マルチセレクト（1〜5件）。6件目はグレーアウト |
| 人数 | ステッパー（1〜15名）。デフォルト: 2名 |
| 車種 | プリセット選択 or カスタム燃費入力。EV対応 |
| バリデーション | 都道府県・人数・車種がすべて入力済みで「次へ」活性 |
| エラー | DR-INP-002、DR-INP-003、DR-INP-005、DR-INP-007 を参照 |

### P-04 入力 Step 3

| 項目 | 仕様 |
|---|---|
| 予算 | 総額 or 1人あたり切替。任意入力（未入力 = 無制限） |
| 優先軸 | マルチ選択：景観・穴場・温泉・絶景・グルメ・体験 |
| 高速道路利用 | トグル（デフォルト: ON） |
| 希望出発時刻 | 時刻ピッカー（デフォルト: 08:00） |
| 連続走行上限 | ステッパー（30分〜240分、30分刻み。デフォルト: 120分） |
| ETCカード | トグル（デフォルト: ON） |
| 駐車スペース | 標準 / 大型車可 切替 |

### P-05 入力 Step 4（確認画面）

| 項目 | 仕様 |
|---|---|
| 表示内容 | Step 1〜3 の全入力内容をサマリー表示 |
| 編集 | 各セクションに「変更」リンク → 該当ステップに戻る |
| 送信ボタン | 「ルートを生成する」。押下後 P-06 へ遷移 |

### P-06 生成中（ローディング）

| 項目 | 仕様 |
|---|---|
| 表示 | プログレスバー + ステップ表示（POI検索中 / ルート計算中 / 費用計算中 / AIコメント生成中） |
| タイムアウト | 30秒後に DR-RTE-003 エラーへ遷移 |
| キャンセル | 「キャンセル」ボタンで P-05 に戻る |

### P-07 ルート候補一覧

| 項目 | 仕様 |
|---|---|
| 表示 | ルートカード × 3案。スコア降順で表示 |
| カード内容 | ルート名・スコア星・総距離・総時間・総費用・1人あたり費用・費用内訳バー・タイムライン・地図プレビュー・AIコメント |
| 並び替え | スコア順（デフォルト）/ コスト順 / 時間順 |
| アクション | 「編集する」「このルートを選ぶ」「LINEで共有」の3ボタン |

### P-08 ルート詳細・編集

| 項目 | 仕様 |
|---|---|
| POI操作 | ドラッグ&ドロップで並び替え。「＋追加」でPOI検索→追加。「×」で削除 |
| 再計算 | POI変更後3秒以内に費用・所要時間を自動再計算（DR-RTE参照） |
| 予算警告 | 費用が予算超過時に赤バナーを表示 |
| 保存 | 「この内容で確定」で P-07 に戻り、編集後ルートを先頭表示 |

### P-10 LINE共有

| 項目 | 仕様 |
|---|---|
| 共有URL | 自動生成された短縮URL表示＋コピーボタン |
| QRコード | URLのQRコードを表示（ダウンロード可） |
| LINEボタン | 「LINEで送る」ボタン → LINE Messaging API 経由で Flex Message を送信 |
| 有効期限 | 「このリンクは7日間有効です」を明示 |

### P-12 共有閲覧（メンバー用）

| 項目 | 仕様 |
|---|---|
| アクセス | 認証不要。short_code で参照 |
| 表示内容 | P-07 のルートカードと同等（編集不可） |
| 参加ボタン | 「参加する」ボタン → 名前入力 → approvals テーブルに登録 |
| 期限切れ | DR-AUTH-003 エラー画面を表示 |
